17. Troubleshooting Cheat Sheet
==================================================
If pod is CrashLoopBackOff:
kubectl describe pod POD_NAME -n devsecops-dev
kubectl logs POD_NAME -n devsecops-dev

If service is not working:
kubectl describe svc SERVICE_NAME -n devsecops-dev
kubectl get endpoints SERVICE_NAME -n devsecops-dev

If HPA shows unknown:
kubectl top pods -n devsecops-dev
kubectl describe hpa node-app-hpa -n devsecops-dev

If DB health fails:
kubectl exec -n devsecops-dev deployment/node-app -- printenv | grep POSTGRES
kubectl logs -n devsecops-dev deployment/postgres --tail=80

If Redis health fails:
kubectl exec -n devsecops-dev deployment/node-app -- printenv | grep REDIS
kubectl logs -n devsecops-dev deployment/redis --tail=80

If image is old:
docker build --no-cache -t ghcr.io/jcsa2030/elhalawany-devops-lab:security .
docker push ghcr.io/jcsa2030/elhalawany-devops-lab:security
kubectl rollout restart deployment/node-app -n devsecops-dev
